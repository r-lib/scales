# Modify colour transparency

Vectorised in both colour and alpha.

## Usage

``` r
alpha(colour, alpha = NA)
```

## Arguments

- colour:

  colour

- alpha:

  new alpha level in \[0,1\]. If alpha is `NA`, existing alpha values
  are preserved.

## See also

Other colour manipulation:
[`col2hcl()`](https://scales.r-lib.org/dev/reference/col2hcl.md),
[`col_mix()`](https://scales.r-lib.org/dev/reference/col_mix.md),
[`colour_manip`](https://scales.r-lib.org/dev/reference/colour_manip.md),
[`muted()`](https://scales.r-lib.org/dev/reference/muted.md)
