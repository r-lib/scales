# Regularly spaced dates

**\[superseded\]**

Use
[`breaks_width()`](https://scales.r-lib.org/dev/reference/breaks_width.md)
instead.

## Usage

``` r
date_breaks(width = "1 month")
```

## Arguments

- width:

  an interval specification, one of "sec", "min", "hour", "day", "week",
  "month", "year". Can be by an integer and a space, or followed by "s".
  Fractional seconds are supported.
