# Demonstrate scales functions with ggplot2 code

These functions generate ggplot2 code needed to use scales functions for
real code.

## Usage

``` r
demo_continuous(x, ...)

demo_log10(x, ...)

demo_discrete(x, ...)

demo_datetime(x, ...)

demo_time(x, ...)

demo_timespan(x, ...)
```

## Arguments

- x:

  A vector of data
