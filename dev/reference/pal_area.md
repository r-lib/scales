# Area palettes (continuous)

Area palettes (continuous)

## Usage

``` r
pal_area(range = c(1, 6))

area_pal(range = c(1, 6))

abs_area(max)
```

## Arguments

- range:

  Numeric vector of length two, giving range of possible sizes. Should
  be greater than 0.

- max:

  A number representing the maximum size.
