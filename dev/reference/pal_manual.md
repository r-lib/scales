# Manual palette (discrete)

Manual palette (discrete)

## Usage

``` r
pal_manual(values, type = NULL)

manual_pal(values, type = NULL)
```

## Arguments

- values:

  vector of values to be used as a palette.

- type:

  A string giving the type of return values. Some example strings
  include `"colour"`, `"numeric"`, `"linetype"` or `"shape"`.
