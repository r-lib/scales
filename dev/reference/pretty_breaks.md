# Superseded interface to `breaks_pretty()`

**\[superseded\]**

These functions are kept for backward compatibility; you should switch
to
[`breaks_pretty()`](https://scales.r-lib.org/dev/reference/breaks_pretty.md)
for new code.

## Usage

``` r
pretty_breaks(n = 5, ...)
```

## Arguments

- n:

  Desired number of breaks. You may get slightly more or fewer breaks
  that requested.

- ...:

  other arguments passed on to
  [`pretty()`](https://rdrr.io/r/base/pretty.html)
