# Superseded interface to `label_wrap()`

**\[superseded\]**

These functions are kept for backward compatibility; you should switch
to
[`label_wrap()`](https://scales.r-lib.org/dev/reference/label_wrap.md)
for new code.

## Usage

``` r
wrap_format(width)
```

## Arguments

- width:

  Number of characters per line.
